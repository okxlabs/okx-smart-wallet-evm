# Diagrams

This folder contains visual diagrams for the OKX Smart Wallet system.

## Available Diagrams

- **Contract Infrastructure** - Overall contract architecture and relationships between product, service and contract layers
- **Account Creation Flow** - Account creation options including Smart Wallet contract deployment or delegation via EIP-7702
- **Execution Flow** - Three execution modes and their flows: direct execution, relayer execution, and ERC-4337 execution paths via the Smart Wallet
- **Recovery Flow** - Account recovery process including recovery trigger, verification, and ownership addition
- **Owner Validation Types** - Owner validation mapping showing how different owner types (passkey, ECDSA, multi-sig) map to their specific validators
